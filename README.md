# MeshLink

> Private, offline communication without the internet.

MeshLink is an Android-based offline mesh communication prototype designed to allow nearby devices to discover each other and exchange messages without relying on traditional internet connectivity.

## Features

- 📡 Nearby device discovery
- 💬 Offline messaging
- 🔗 Mesh-based routing
- 💾 Store-and-forward messaging
- 🧪 Network simulator for testing
- 🎨 Modern Android UI
- 🌙 Light / Dark / System themes
- ⚙️ Settings
- 🔒 Local-first communication

## Tech Stack

- Kotlin
- Android
- Google Nearby Connections
- Gradle
- JUnit
